# Utvecklingsmiljö och README

I den här övningen lär jag mig att använda Git Bash och Visual Studio Code. Jag har skapat mappar och filer med terminalkommandon och skrivit en README-fil med Markdown-syntax.

## Kommandon jag har använt

- `mkdir` skapar en ny mapp.
- `cd` används för att gå till en mapp.
- `touch` skapar en ny fil.
- `ls` visar innehållet i en mapp.
- `code` öppnar en fil eller mapp i Visual Studio Code.
